Form1 - код игры
Суть игры заключается в том что два игрока поочереди выбирают кнопки один Х другой О
После нажатия на кнопку на ней появится знак игрока Х или О
Для победы игроку необходимы совместить в ряд 3 занятые своим знаком кнопки
Если все кнопки заняты но в 3 ряд кнопки не заняты, игра считается ничьей
Игру можно перезагрузить, нажав на кнопку Начать заново
При победе или ничьей сверху кнопок появится надпись кто победил или ничья
